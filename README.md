# Bartresen Küche

Projekt für einen Bartresen in der Küche.

## Struktur
- `index.html` - GitHub Pages Website
- `docs/` - Dokumentation
  - `DESCRIPTION.md` - Projektbeschreibung
  - `BOM.md` - Stückliste (Bill of Materials)
  - `DRAWINGS.md` - Technische Zeichnungen
- `assets/` - Bilder, SVGs, 3D-Modelle
- `webgl/` - WebGL/Three.js Anwendung
